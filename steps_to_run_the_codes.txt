STEPS:
------ common steps -------
1. download the original dataset (exactly the same as the original pipeline, run dataset_download.py)
2. run preprocessing.py (exactly the same as the originl pipeline) to get tne masks

----- specific for HPF and DFF ---------
3. run prefiltering.py under the project directory, so it will generate and save the original images in channel 1, the filtered features in channels 2 and 3. 
The resultant folders will be "./TACK_Tunnel_Data/4_img_sobelxy", "./TACK_Tunnel_Data/4_img_sobelmaglap", and "./TACK_Tunnel_Data/4_img_sobelmag_gabor". Note here to do this you want to install OpenCV by pip install opencv-python.
4. now step into the folder "dff_HPF_multi_model", download all the models we want to do feature extraction to "./models" directory, and run the notebook "dff_hpf_multi_model.ipynb".
